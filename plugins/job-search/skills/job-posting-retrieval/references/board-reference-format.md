# Board Reference Format

Each reference describes one board and contains:

- Board name and URL patterns
- Detection guidance
- Preferred retrieval approach
- Scope and completeness checks for board/list inventory
- Identity and canonical-link verification rules
- Known failures and recovery steps
- Evidence-quality notes
- Verification date
- Confidence
- Privacy constraints

References must not contain credentials, tokens, cookies, unrelated private
content, or unverified selectors. A reference is provisional until verified
against the current page. New references must not require edits to this
skill's mechanics — they're additive, loaded only after board detection.
